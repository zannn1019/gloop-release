# Gloop

A little liquid creature that lives in the notch at the top of your Windows screen: music and
lyrics, notifications, today's calendar, a clipboard history, screenshots you can drag into a
chat, a quick control center, meeting transcripts, and an AI assistant you can ask anything.

## Download

**[Download the latest Gloop-win-Setup.exe](https://github.com/zannn1019/gloop-releases/releases/latest)**

Run it: Gloop installs just for you (no admin needed), starts right away, and starts with Windows.
It updates itself when a new version comes out.

Windows 10 (2004 or later) or Windows 11, 64-bit.

### "Windows protected your PC"?

Gloop isn't code-signed yet, so Windows SmartScreen may warn about it the first time. Click
**More info › Run anyway**.

## Good to know

- **Settings:** right-click the little guy › Settings. Turn off any feature you don't use under
  Features.
- **Ask Gloop** works with your own API key for Claude, Gemini, OpenAI (or a compatible service),
  or a model on your own PC through Ollama.
- **Gmail and Google Calendar** (new mail on the notch, the Today tab, Join for calls) need a free
  Google Cloud "Desktop app" key of your own, with the Gmail API and Google Calendar API turned on.
  Settings › Pop-ups › Gmail › Connect walks you through it. Everything else works without it.
- **Meeting transcripts** run on your PC by default (a one-time speech-model download); nothing
  is recorded unless you say so.
- **Privacy:** Gloop is hidden from screenshots and screen sharing by default. Clipboard history
  stays in memory. Your API keys are stored encrypted for your Windows account.

## Uninstall

Settings › Apps › Installed apps › Gloop › Uninstall.
